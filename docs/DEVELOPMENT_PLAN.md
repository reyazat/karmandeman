# مسیر اجرایی توسعه کارمند من

تاریخ بازبینی: ۲۶ اکتبر ۲۰۲۶. مبنا: KM-ENG-001، PRD 1.3، Strategy 1.3 و Runbook 1.1. این سند ترتیب اجرایی backlog است؛ جایگزین نیازمندی‌ها، مجوز پرداخت یا تأیید انتشار نیست.

## نقطه شروع واقعی

بخش‌هایی از Foundation، Brand، Project و Gift Ledger نوشته شده‌اند. محصول هنوز ورودی تجاری نمی‌گیرد و خروجی قابل استفاده تولید نمی‌کند. تعداد کلاس‌ها و سبزبودن تست نمونه معیار درصد پیشرفت MVP نیست. شواهد در [گزارش ممیزی](PROJECT_AUDIT_2026-10-26.md) ثبت می‌شود.

دو نام‌گذاری را از هم جدا کنید: **اولویت P0 در PRD** یعنی قابلیت ضروری؛ **فاز P0 در Strategy** یعنی Discovery. Telegram MVP در Strategy فاز P1 است، ولی قابلیت‌های ضروری آن همچنان اولویت P0 دارند. در تسک‌ها هر دو را بنویسید. این رفع ابهام است و دامنه مصوب را تغییر نمی‌دهد.

JSON فقط اولین خروجی برای تست است؛ CSV/PDF/ZIP/کاتالوگ همچنان خروجی ضروری MVP هستند. ثبت/نگه‌داری رخداد هزینه و کیفیت از اولین run انجام شود و به پایان پروژه موکول نشود.

## اصلاح ترتیب قبلی

PRD §۱۵ «Ledger، امنیت و Admin» را عمدتاً در هفته ۱۰ قرار داده بود؛ طبق dependencyهای همان PRD §۱۴، Policy، quota، ledger و recovery پایه باید پیش از پردازش هزینه‌دار و ورودی واقعی آماده شوند. هفته‌ها تخمین تاریخی‌اند؛ عبور از گام‌ها با شاهد انجام می‌شود. Discovery، backup و بررسی قانونی از اکنون آغاز می‌شوند؛ راه‌اندازی با داده واقعی پس از gate انجام می‌شود.

## کارهایی که فعلاً وارد اجرا نمی‌شوند

وب Workspace کامل، Agent Builder، چند کارمند، محصولات متغیر، XLSX پیشرفته، اتصال مستقیم و انتشار در Woo، و پرداخت ریالی داخل ربات. Mini Review فقط با شواهد نیاز کاربران و در حد اصلاح/تأیید مجاز است. NextPay/Stars یک تصمیم جدا با gate رسمی است؛ enum یا جدول پرداخت مجوز فعال‌سازی محسوب نمی‌شود.

## تعریف پایان هر تسک

تسک با ID نیازمندی و سناریوی مثبت/منفی/جداسازی tenant ثبت شود؛ برای رفتار مالی/صفی replay و PostgreSQL concurrency لازم است. خروجی شامل قرارداد API/schema، کد در لایه مصوب، تست اجراشده و نتیجه واقعی، محدودیت‌ها و اثر migration/rollback باشد. تست پیاده‌نشده، ابزار پیکربندی‌نشده و نتیجه وابسته به سرویس mock باید مشخص بماند. هر تصمیم خلاف استاندارد پیش از کدنویسی ADR می‌خواهد.
