# ADR-008 — پایدارسازی پایه پیش از Intake

تاریخ: 2026-10-26. وضعیت: پذیرفته‌شده برای اصلاح پیاده‌سازی موجود؛ تغییری در دامنه MVP یا استاندارد KM-ENG-001 نمی‌دهد.

## تصمیم

- در پایلوت فقط مالک فعال Workspace فعال مجوز عملیات دارد. نقش‌های دیگر تا طراحی و تست فاز تیمی مجاز نیستند. Policy مستقل از فیلتر Repository اجرا می‌شود.
- دریافت webhook، تغییر دامنه، dedupe و درج اعلان خروجی در یک transaction دیتابیس انجام می‌شود. خطای دامنه rollback و پاسخ 5xx می‌دهد تا تلگرام retry کند. هیچ HTTP خارجی در transaction اجرا نمی‌شود.
- اعلان‌ها از صف اختصاصی database به نام `telegram` خوانده می‌شوند؛ اتصال `telegram` به همان DB دامنه است و تنظیم اتصال جداگانه را نمی‌پذیرد. درج job پیش از commit، درج داخلی دیتابیس است؛ ارسال خارجی فقط پس از مشاهده commit توسط worker انجام می‌شود. payload رمز‌شده است.
- worker لازم: `php artisan queue:work telegram --queue=telegram --sleep=1 --timeout=20 --tries=5`؛ سرویس `telegram_worker` در Compose reference تعریف شده است. Horizon صف Redis را اجرا می‌کند و جای این worker را نمی‌گیرد. فعال‌سازی worker و تست staging شرط release است؛ این تغییر خودش deploy نمی‌کند.
- Telegram برای sendMessage کلید idempotency ندارد؛ retry پس از timeout مبهم ممکن است اعلان تکراری بدهد. دامنه/پروژه/هدیه تکراری نمی‌شود؛ ادعای exactly-once delivery نداریم.
- تا پیاده‌سازی چرخه رزرو/مصرف/آزادسازی با قرارداد کامل، primitive فعلی ledger فقط grant مثبت می‌پذیرد. سایر نوع‌ها fail closed هستند؛ خرید یا پردازش پولی فعال نمی‌شود.
- قبل از صدور توکن، initData باید تازه، دارای فیلدهای scalar بدون تکرار، امضای معتبر و User معتبر باشد. توکن تاریخ انقضا دارد و مسیر احراز هویت محدودیت نرخ دارد.

## پیامد و محدودیت

این اصلاح یک پایه امن‌تر است، نه پایان Epicهای A/B/H. رضایت نسخه‌دار، حذف داده، تاریخچه کامل حافظه، شناسه عمومی opaque، رزرو/تسویه، ثبت رخدادهای جامع و workflowهای n8n همچنان gate مستقل دارند. هیچ migration روی دیتابیس موجود یا production اجرا نمی‌شود؛ فقط تست‌های موقت مجازند.

مرجع صف: [Laravel 13 queues](https://laravel.com/docs/13.x/queues). استفاده از database به‌عنوان outbox محدود، تصمیم همین پروژه است؛ مستند Laravel به‌تنهایی اثبات atomicity برنامه نیست و تست لازم دارد.
